# AEON — The Agent Economy

AEON is an agent-native commerce experience built for the WebMCP Challenge.

> Give your agent a goal. Give it boundaries. Let it do the work.

## Core idea

A human gives AEON a high-level commerce mission and an Agent Constitution. The agent can search, compare, assemble bundles, and negotiate through structured WebMCP tools. Consequential purchasing actions remain under explicit human control.

## Demo mission

> Build me the best creator setup under ₦1M. Prioritize performance and audio quality. You can negotiate, but ask me before purchasing.

## Status

Foundation phase. Product requirements and technical specification are documented in `docs/`.
